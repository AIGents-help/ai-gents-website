## Implemented (existing Supabase project only)
- `ag_stripe_customer_links`: one Stripe customer mapping per AI Gents client and test/live mode. Browser cannot write mappings.
- `ag_invoices`: account- and mode-bound Stripe invoice IDs with last-synced timestamp; browser users cannot update financial status or forge bindings.
- `ag_stripe_event_receipts`: event receipts for webhook replay detection, invisible to app users.
- `ag-office-stripe-test`: JWT-authenticated, owner/admin-only, **test-only** endpoint for Stripe draft preparation.
- `ag-office-stripe-webhook`: webhook receiver requiring a Stripe signature and correct test mode; handles finalized, paid, voided, uncollectible and payment-failure updates.
- Billing UI: indicates correct account verified, reports readiness via protected function and shows **Prepare TEST Stripe draft** only if configured and enabled.
- `auto_advance=false` and `collection_method=send_invoice`. No send, finalize, collect or live-mode action exists in the gateway.
- Stripe calls carry stable per-object idempotency keys.
