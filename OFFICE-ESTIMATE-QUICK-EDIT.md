# AI Gents Office — Collapsible Internal Estimate Quick Editing

## Updated workflow
- The owner/staff-only **Internal Estimate — Selected Components** now starts **collapsed**. Its summary always displays the live one-time and monthly AI Gents totals.
- Expand it manually. It stays open across saves and scope reloading because the existing per-project accordion-state tracker preserves the `estimate` panel.
- Each selected line displays an immutable reference benchmark under the component label.
- **Click the component name** to open its category and individual fee editor and scroll to the item.
- **Edit Setup or Monthly directly in the estimate**; values synchronize to that component's existing fee editor and the subtotal updates immediately without re-creating the active input DOM.
- Editing in the individual fee editor likewise updates the quick-edit estimate field in place.
- **Save estimate changes** at the bottom saves all edited component prices and other changed fee settings together. If no unsaved changes exist it is disabled.
- To change third-party monthly cost or quantity, use the component's individual fee editor (the linked component name opens it). Those changes also count toward the single bottom save.
- Copying a draft estimate is disabled while unsaved fees remain. The system prevents adding/removing selected components before saving outstanding quote edits to avoid accidental loss.

## Safety
- A single staff-only Postgres RPC `ag_save_component_quote_batch` atomically saves all changed rows in a transaction.
- The database validates each component belongs to the current project, constrains fee and quantity ranges, rejects duplicate component entries, and compares each price record's `updated_at` to protect against overriding another staff user's more recent edits.
- The immutable benchmark snapshot is never changed by the batch update.
- Unauthorized authenticated users are rejected.
- No invoice, Stripe payment, client message, or subscription is generated by a quote edit.
